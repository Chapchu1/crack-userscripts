1. crack-hide-input-model-button.user.js : 설치용 스크립트 본체
2. crack-hide-input-model-button.meta.js : 자동 업데이트 확인용 메타 파일
3. crack-hide-input-model-button-설치안내.txt : 이 안내문

[GitHub에 올리는 방법]
1. ZIP 압축을 풉니다.
2. 기존 Chapchu1/crack-userscripts 저장소의 main 브랜치를 엽니다.
3. 저장소 최상위에서 Add file → Upload files를 누릅니다.
4. 압축을 푼 파일 3개를 올리고 Commit changes를 누릅니다.
   ZIP 자체나 ZIP을 푼 상위 폴더를 올리지 말고, 파일들을 직접 올려 주세요.

기존 모바일 유틸/테마/Suite와는 별도 파일명입니다.
다른 스크립트나 저장소의 기존 README를 덮어쓰지 않습니다.
이 배포본은 위 저장소와 main 브랜치의 최상위 경로에 맞춰져 있습니다.
다른 저장소·브랜치·폴더에 올리면 두 JS 파일의 홈페이지/업데이트/다운로드 주소도 함께 바꿔 주세요.

[업로드 후 사용할 설치 링크]
https://raw.githubusercontent.com/Chapchu1/crack-userscripts/main/crack-hide-input-model-button.user.js

위 링크는 업로드할 파일의 예정 주소입니다. 이 ZIP 제작 과정에서는 GitHub에 직접 업로드하지 않았습니다.
사용자는 설치 링크에서 탬퍼몽키로 설치합니다.
설치 창이 뜨지 않으면 파일 내용 전체를 탬퍼몽키 → 새 스크립트에 붙여넣고 저장합니다.
기존 1.0.0을 붙여넣어 설치했다면, 이번 GitHub 배포본으로 한 번 교체하여 업데이트 주소를 등록해 주세요.
스크립트 이름과 namespace는 유지했습니다. 같은 스크립트를 두 개 켜 두지 마세요.

[사용 방법]
설치 후 크랙 채팅방을 새로고침합니다.
자동으로 숨겨지지 않으면 탬퍼몽키에서 이 스크립트의 '숨길 버튼 직접 지정'을 누르고,
입력창 아래의 번개 모델 버튼을 한 번 누릅니다.
'모델 버튼 다시 표시'로 복원할 수 있습니다.
'직접 지정 초기화 (자동 감지 유지)'는 수동으로 저장한 버튼 식별 정보만 지웁니다.

[이후 업데이트]
본체와 메타 파일의 @version을 같은 새 버전으로 올리고, 두 파일을 같은 이름으로 덮어씁니다.
@name, @namespace, @updateURL, @downloadURL은 유지합니다.
자동 업데이트 확인 시점은 각 사용자의 탬퍼몽키 설정에 따라 달라집니다.

[확인 범위]
원본 1.0.0의 실행 코드는 그대로이며 GitHub 배포 주소와 메타 파일을 추가했습니다.
JavaScript 문법과 압축파일 무결성을 확인했습니다.
실제 크랙 로그인 채팅창에서의 동작은 아직 확인하지 못했습니다.
