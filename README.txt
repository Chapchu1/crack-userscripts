크랙 메시지 바로 복사·삭제 1.0.0
별도 추가 스크립트 / 새 기능의 실기기 검증 대기

추가한 기능
- 내가 보낸 메시지: 아래 점 세 개 옆에 전체 복사 + 삭제 아이콘.
- AI 답변: 사진의 연필(수정) 아이콘 옆에 삭제 아이콘.
  연필을 찾을 수 없는 화면에서는 점 세 개 옆에 배치합니다.
- 전체 복사는 원문 전체를 줄바꿈, 이모지, 마크다운 그대로 복사합니다.
- 작은 선 아이콘이 기존 글자색을 따라 라이트/다크 모드에 맞춰집니다.
- 새 삭제 아이콘을 누르면 기존 크랙의 해당 메시지 삭제 기능을 연결합니다.
  메시지와 삭제창의 대상이 확인되면 확인창을 자동으로 진행합니다.
  삭제한 메시지는 되돌릴 수 없습니다.

아직 확인이 필요한 부분
실제 휴대폰의 크랙 삭제창이 대상 정보를 제공하는지는 확인하지 못했습니다.
대상을 확인할 수 없으면 자동 삭제를 멈추고 기존 확인창을 그대로 남깁니다.
따라서 실기기에서 '아이콘 한 번으로 삭제'가 동작한다고 아직 확정할 수 없습니다.
모의 화면의 브라우저 테스트와 실제 크랙 사용 검증은 구분합니다.

GitHub에 올릴 파일
ZIP을 풀어 아래 두 파일을 기존 저장소의 최상위에 올리세요.
1. crack-message-quick-actions.user.js
2. crack-message-quick-actions.meta.js
ZIP 파일 자체를 올리는 방식이 아닙니다.
README/VALIDATION/tests는 설명과 재검증용이며 설치에 필수는 아닙니다.
다른 스크립트 파일을 이 파일로 덮어쓰지 마세요.

설치
GitHub 업로드 후 crack-message-quick-actions.user.js의 Raw를 열어
Tampermonkey에 별도 스크립트로 설치하고, 크랙을 한 번 새로고침합니다.
업데이트 주소는 기존 Chapchu1/crack-userscripts 저장소의 main 기준입니다.

함께 켜 둘 스크립트
- 기존 모바일 유틸 합본, 테마, Chasm: 기존 설정 유지.
- '크랙 생성 실패 메시지 삭제 보정': 켜 두기. 사용자가 작동을 확인한 버전은 수정하지 않았습니다.
- 이전 삭제 오류 진단용 스크립트: 꺼 두기.

기존 점 세 개 메뉴에서 직접 삭제하면 원래 확인창이 유지됩니다.
생성·편집 중이거나, 선택한 메시지/방/본문이 바뀌면 자동 삭제는 멈춥니다.
반복해서 누르더라도 같은 진행 중 삭제를 중복 실행하지 않습니다.

확인할 항목
- 보낸 메시지 아래에 복사/삭제, AI 연필 옆에 삭제 아이콘이 보이는지.
- 복사한 내용이 보낸 원문 전체인지.
- 삭제 가능한 테스트 메시지에서 새 아이콘으로 해당 메시지만 삭제되는지.
- 생성 실패 메시지에도 기존 오류 보정이 함께 작동하는지.

끄기
이 새 스크립트만 끈 뒤 새로고침하면 추가 아이콘이 없어집니다.
